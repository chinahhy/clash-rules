# sing-box

- [linux.json](linux.json)：ImmortalWrt 裸核配置，mixed 端口 7893。
- [iphone.json](iphone.json)：原有 iPhone 配置。

沿用教程现成的 xream 远程脚本，无需另存自定义 JS。本模板的六地区组名称不同，请先使用下方适配链接的参数，之后直接更新 `linux.json` 即可。

<details>
<summary>Sub-Store 设置</summary>

1. 创建名为 `singbox` 的组合订阅。
2. 将 `linux.json` 导入文件管理，作为本地文件；在自己的 Sub-Store 文件内容中，将两处 `secret` 改为自己的面板口令。口令不写入 GitHub，也不再设置额外的 secret 脚本参数。
3. 文件添加“脚本操作 → 链接”，复制[教程同款远程脚本的适配链接](https://raw.githubusercontent.com/xream/scripts/main/surge/modules/sub-store-scripts/sing-box/template.js#type=%E7%BB%84%E5%90%88%E8%AE%A2%E9%98%85&name=singbox&outbound=%F0%9F%95%B3%5E%E2%99%BB%EF%B8%8F%5C%20%E8%87%AA%E5%8A%A8%E9%80%89%E6%8B%A9%24%F0%9F%8F%B7%5E%28%28%3F%21%28%E7%9B%B4%E8%BF%9E%7C%E5%89%A9%E4%BD%99%7C%E6%B5%81%E9%87%8F%7C%E5%A5%97%E9%A4%90%7C%E5%AE%98%E7%BD%91%7C%E7%BD%91%E7%AB%99%7C%E4%B8%93%E4%B8%9A%7C%E5%88%B0%E6%9C%9F%7C%E8%BF%87%E6%9C%9F%7C%E9%87%8D%E7%BD%AE%7C%E8%AE%A2%E9%98%85%7C%E6%9B%B4%E6%96%B0%E8%AE%A2%E9%98%85%7C%E6%9C%80%E6%96%B0%7C5%E5%80%8D%7C%E4%B8%8B%E8%BD%BD%7C%E5%85%AC%E5%91%8A%7C%E5%AE%A2%E6%9C%8D%7C%E5%B7%A5%E5%8D%95%7C%E5%80%8D%E7%8E%87%7C3x%7C5x%7C7x%7C10x%29%29.%29%2A%24%0A%F0%9F%95%B3%5E%F0%9F%87%AF%F0%9F%87%B5%5C%20%E6%97%A5%E6%9C%AC%E8%8A%82%E7%82%B9%24%F0%9F%8F%B7%E2%84%B9%EF%B8%8F%5E%28%3F%21.%2A%28%3F%3A%E6%97%A5%E6%9C%AC-%E4%B8%AD%E8%BD%AC%2002%29%29%28%3F%3A%28%3F%3D.%2A%28%E6%97%A5%7Cjp%7Cjapan%29%29%5E%28%28%3F%21%28%E5%89%A9%E4%BD%99%7C%E5%A5%97%E9%A4%90%7C%E5%AE%98%E7%BD%91%7C%E4%B8%93%E4%B8%9A%7C3x%7C%E6%9B%B4%E6%96%B0%E8%AE%A2%E9%98%85%7C5x%7C%E6%9C%80%E6%96%B0%7C5%E5%80%8D%7C%E4%B8%8B%E8%BD%BD%29%29.%29%2A%24%29%0A%F0%9F%95%B3%5E%F0%9F%87%B9%F0%9F%87%BC%5C%20%E5%8F%B0%E6%B9%BE%E8%8A%82%E7%82%B9%24%F0%9F%8F%B7%E2%84%B9%EF%B8%8F%28%3F%3D.%2A%28%E5%8F%B0%7Ctw%7Ctaiwan%7C%E5%8F%B0%E6%B9%BE%7Ctaipei%7C%E5%8F%B0%E5%8C%97%7Ctaichung%7C%E5%8F%B0%E4%B8%AD%7Ckaohsiung%7C%E9%AB%98%E9%9B%84%29%29%5E%28%28%3F%21%28%E5%89%A9%E4%BD%99%7C%E5%A5%97%E9%A4%90%7C%E5%AE%98%E7%BD%91%7C%E4%B8%93%E4%B8%9A%7C3x%7C%E6%9B%B4%E6%96%B0%E8%AE%A2%E9%98%85%7C5x%7C%E6%9C%80%E6%96%B0%7C5%E5%80%8D%7C%E4%B8%8B%E8%BD%BD%29%29.%29%2A%24%0A%F0%9F%95%B3%5E%F0%9F%87%AD%F0%9F%87%B0%5C%20%E9%A6%99%E6%B8%AF%E8%8A%82%E7%82%B9%24%F0%9F%8F%B7%E2%84%B9%EF%B8%8F%28%3F%3D.%2A%28%E6%B8%AF%7Chk%7Chongkong%7Chong%20kong%29%29%5E%28%28%3F%21%28%E5%89%A9%E4%BD%99%7C%E5%A5%97%E9%A4%90%7C%E5%AE%98%E7%BD%91%7C%E4%B8%93%E4%B8%9A%7C3x%7C%E6%9B%B4%
